# Lakeglass

Lakeglass is an offline-capable Lake Michigan beach glass field guide and personal accession archive.

## Included

- Evidence-based field identification flow
- Lake Michigan color occurrence index and regional context
- Local specimen archive using IndexedDB
- Export/import of collection data
- Installable PWA manifest and app icons
- Service worker for offline use
- No accounts, camera identification, or photo storage

## GitHub Pages

1. Open **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select `main` and `/ (root)`, then save.
4. Open the published URL in Safari on iPhone and choose **Share → Add to Home Screen**.

The app is fully static; no server or database is required for version 1.
